# 大站模式设计

创建日期：2026-11-11。更新日期：2026-11-16。状态：规则已确认，准备期入口调整为所有尺寸直接可见；本次入口展示调整未运行测试。既有实现结果及实机边界集中记录在[验证记录](standing-break-validation.md)。

## 用户已明确的需求

- 新增「大站」模式，允许用户站着继续工作，并把这一段作为休息。
- 首版通过用户手动点击确认站立，不增加自动姿态判断。
- 站立休息默认采用普通休息的两倍时长，并允许自定义。
- 站立休息期间，触控输入和摄像头监控不阻断休息倒计时。
- 界面名称采用「大站 · 站立休息」，说明为“站起来，手上的事可以继续”；「大站理论」作为趣味表达，不宣称科学或健康效果。
- 大站期间关闭摄像头，保留原监控偏好，后续需要监控的轮次再重新开启。此项为第二轮 Q7 的明确回答。
- 大站只覆盖当前休息轮，用户通过按钮开始、暂停、继续；默认休息自动逻辑及后续轮次的感知偏好保持。设置只增加大站时长，不增加大站默认模式。此项为 Q8 的明确回答。
- 用户在 Q9 明确选择只在正式休息前的准备期提供大站选项；普通休息开始后不再转换。原来讨论的重开与进度折算方案均不实施。

领域定义见[站立休息](../GLOSSARY.md)。本记录保留已确认的规则与取舍；本轮产品规格、契约、架构和路线图同步更新，不代表已经发布安装包或完成所有实机验收。

## 已确认的决策树

用户接受两倍跟随、短长独立覆盖、名称、摄像头临时释放及“默认自动逻辑 + 本轮手动大站”。最后通过把入口限定在正式休息前，消除了已有进度如何换算的分支；没有引入新的全局默认方式。

```text
大站：手动声明站立，允许继续操作电脑
├─ 默认自动休息 + 本轮手动大站
│  ├─ 大站只覆盖当前短休／长休，不加入默认休息模式选项
│  ├─ 「已站立，开始大站」合并选择、声明与开始
│  └─ 入口仅在正式休息前准备期；开始后消失，不重开、不折算
├─ 两倍基准为用户设置的普通短休／长休
├─ 短休、长休分别覆盖，未覆盖时跟随两倍
│  └─ 设置边界：短休 1–120 分钟、长休 1–180 分钟；可恢复跟随两倍
├─ 「大站 · 站立休息」，作为趣味产品表达
├─ 只有已进入的大站轮由按钮开始、暂停、继续
└─ 大站期间释放摄像头，保留选择，下轮按需恢复
```

普通短休从 5 分钟改为 8 分钟后，未自定义的站立短休从 10 分钟变为 16 分钟。自定义后保留用户输入的分钟数；站立短休和长休独立设置，不新增第三种倍率配置。

## 两个维度与切换入口

感知方式回答“根据什么获取在场／离席信号”；休息方式回答“本轮怎样休息、什么条件下计时”。大站不加入「监控／触控」二选一。

| 休息方式 | 现有条件或已明确的需求 |
| --- | --- |
| 活动休息 | 使用用户选择的触控或监控，离席代理信号满足时计时。 |
| 桌前休息 | 使用系统输入，无输入达到阈值时计时。 |
| 大站 · 站立休息 | 手动确认后计时，输入及摄像头信号不决定倒计时。 |

原有默认方式入口是「更多 → 设置 → 自动化 → 默认休息模式」，只影响下一轮休息。大站在准备期的所有窗口尺寸中均于轮次标题旁提供直接按钮，包括 160×180 最小窗口；紧凑布局仅缩短文案为「开始大站」，不隐藏按钮。「更多操作」菜单同时保留同一入口。

桌前休息是现有的特殊偏好：即使用户仍在摄像头前，只要停止系统输入达到阈值也可休息。它与活动休息只在选中监控时有实际差异；选中触控时，两者都由系统输入闲置驱动。默认活动休息确实跟随用户选择的监控／触控。大站需求不构成删除既有桌前偏好或改变旧设置的授权。

## 已确认模型：默认自动休息 + 本轮手动大站

Q8 已获用户接受，替代此前尚未接受的“大站也可作为默认方式”的入口建议：

- 保留现有默认休息自动化：普通活动休息按监控／触控判断，既有桌前设置按原规则处理。
- 普通休息首次准备期提供「已站立，开始大站」，按钮合并选择本轮大站、声明站立与开始计时，无额外确认弹窗；所有尺寸均在轮次标题旁直接显示，小窗显示「开始大站」，菜单入口继续保留。
- 大站仅覆盖本轮短休／长休，采用已确认的两倍时长或对应自定义值。设置页只新增大站时长，不将大站加入默认休息模式。
- 只有当前大站轮通过按钮开始、暂停、继续；常规休息保留原自动开始／恢复规则。暂停、睡眠或重启不会结束当前大站轮，也不修改全局默认。
- 大站结束后按原周期推进，后续轮次沿用原监控／触控与休息偏好。“恢复原规则”不等于强制改回活动休息。

例：普通短休为 5 分钟，用户在休息准备阶段点击「已站立，开始大站」，本轮按默认 10 分钟站立休息计时；站着操作电脑不会暂停。不选择时，默认无输入第 30 秒起显示最后 10 秒，第 40 秒开始普通休息；监控模式继续等待摄像头离席。正式计时开始后不再显示大站选项。

入口限制由 Main 校验，不依赖 Renderer 的按钮是否隐藏。轮次保存 `hasStarted`：新建或显式重置为 `false`，首次手动或自动开始即为 `true`。即使开始后零毫秒便暂停，或随后重启应用，也不能把原进度重新当作准备期。旧检查点缺少标记时，非 `idle` 轮次保守视为已经开始，旧等待轮可通过显式重置或后续新轮使用入口。

Q7 已确认的摄像头规则：大站期间释放检测会话，保留已选「监控」设置；进入需要监控的后续轮次时重新初始化并等待新样本。主动释放不得触发摄像头故障回退或改写持久化感知选择。

继续沿用累计有效运行时间、睡眠／锁屏／重启离线不计、跳轮不增加专注统计、重置恢复本轮原时长、时长设置不追改当前轮次等既有边界。大站仅占原休息位置、不增加专注统计；短休后进入下一轮专注，长休后进入下一周期。进入监控专注后等待新鲜在场样本，进入触控专注后仍由用户开始。

## 设置与状态边界

- 大站短休、长休分别采用整数分钟，自定义范围为 1–120 分钟和 1–180 分钟，对应现有普通短休／长休上限的两倍。此范围与最长 `180:00` 的展示一起验证。
- 未自定义时显示「跟随普通休息 ×2」及当前计算结果；选择自定义后保留用户输入的固定分钟数，每项可独立恢复跟随。
- 设置修改用于下一次开始大站，已分配的大站总时长和剩余时间不变；重置恢复当前大站最初分配的时长。
- 大站暂停、睡眠、锁屏、应用重启后保留当前进度，等待用户手动继续；不因输入、摄像头或设置切换自行恢复。
- 大站只提供已确认的开始、暂停、继续与既有重置／跳轮，不新增单独站立计时器、全局大站默认、专注累计或分享功能。
