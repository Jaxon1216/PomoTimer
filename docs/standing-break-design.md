# 大站模式设计访谈

创建日期：2026-11-11。更新日期：2026-11-15。状态：第一轮时长与命名已确认，第二轮入口和生命周期待回答，尚未实施功能。

## 用户已明确的需求

- 新增「大站」模式，允许用户站着继续工作，并把这一段作为休息。
- 首版通过用户手动点击确认站立，不增加自动姿态判断。
- 站立休息默认采用普通休息的两倍时长，并允许自定义。
- 站立休息期间，触控输入和摄像头监控不阻断休息倒计时。
- 界面名称采用「大站 · 站立休息」，说明为“站起来，手上的事可以继续”；「大站理论」作为趣味表达，不宣称科学或健康效果。

领域定义见[站立休息](../GLOSSARY.md)。本记录区分需求、现有行为和待决策方案；产品规格、契约与路线图仍描述已交付行为。

## 两个维度与切换入口

感知方式回答“根据什么获取在场／离席信号”；休息方式回答“本轮怎样休息、什么条件下计时”。大站不加入「监控／触控」二选一。

| 休息方式 | 推荐采用的计时条件 |
| --- | --- |
| 活动休息 | 使用用户选择的触控或监控，离席代理信号满足时计时。 |
| 桌前休息 | 使用系统输入，无输入达到阈值时计时。 |
| 大站 · 站立休息 | 手动确认后计时，输入及摄像头信号不决定倒计时。 |

当前代码的入口是「更多 → 设置 → 自动化 → 默认休息模式」，只影响下一轮休息。主页面的当前方式仅是文本，在宽度不超过 265 px 或高度小于 300 px 时隐藏，不能直接当作最小窗口的唯一操作入口。

第二轮推荐方案（等待回答）：

- Q5：顶栏保留「监控／触控」。休息轮的「…」菜单增加「本轮休息方式」，宽窗口把已有方式文字改为同一选择入口。设置页独立管理默认休息方式和大站时长；临时改本轮不修改默认。已有进度时用“重新开始为大站休息 · 10 分钟”明确告知重开，选择后重新分配该方式的完整时长，并等待站立确认；不引入不同方式的分钟折算。最小窗口显示“大站短休／大站长休”，以免方式文字隐藏后丢失当前含义。
- Q6：每轮点击「已站立，开始」才计时；暂停、睡眠、锁屏或重启后点击「继续大站」才恢复。按钮本身就是用户声明，无额外弹窗；监测不自动开始、暂停或恢复大站。
- Q7：大站期间释放摄像头，保留已选「监控」偏好；进入下一轮需要监控时重新初始化，等待新样本。顶栏在大站期间说明该选择用于后续轮次，不以“切回触控”代替临时释放。

继续沿用累计有效运行时间、睡眠／锁屏／重启离线不计、跳轮不增加专注统计、重置恢复本轮原时长、时长设置不追改当前轮次等既有边界。推荐大站仅占原休息位置、不增加专注统计；短休后进入下一轮专注，长休后进入下一周期。
