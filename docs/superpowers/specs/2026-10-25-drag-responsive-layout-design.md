# 拖拽自适应窗口

用户要求恢复直接拖动边框自适应，取消常规/迷你手动切换。

- 初始内容尺寸保持 360×478，最小恢复 160×180；原生边框由 Main 换算。
- Main 只管理单个窗口的尺寸和会话内位置记忆；删除模式切换 IPC、事件和按钮。
- Renderer 使用 CSS 根据可用宽高调整布局，不监听 resize 发送计时或窗口命令。
- 常规尺寸显示圆环、总时长、周期、状态及控制；窄小窗口收起品牌、快捷入口、总时长和周期，完整保留轮次、状态、监测和 32px 操作按钮。
- 160×180 使用醒目数字和细进度线；220×240 恢复圆环；宽至少 360 且高不超过 240 时使用圆环在左、信息控制在右的布局。
- 菜单限制在视口内；设置、统计单列滚动，返回及保存始终可达。
- resize 不改变 TimerEngine、手动暂停锁、剩余时间或数据库；计时核心与持久化行为不在本轮修改。
- 验收包括 160×180、160×478、220×240、320×300、360×478、360×180、480×240、720×480 及关键断点两侧；验证长时长、休息等待和输入故障。

本轮不包含依赖升级、计时精度修复、摄像头和其他功能扩展。
